## 1. Что исправлено и добавлено

### 1.1. ФИКС: «не получается загрузить таблицу для заявки»
Причина: генератор создавал xlsx, но не подключал его к сессии, а сценария
«открыть готовую заявку» не было.

Теперь окно **«Заявка»** (кнопки «Заявка (PIM → xlsx)» / «Генератор заявки»):
- **A · Открыть существующую заявку (.xlsx)** — нативный диалог выбора файла
  (A(1)=Код LM, D(4)=Штрих-код). После открытия товары сопоставляются
  автоматически (Код LM, название, строка Excel) — в шапке окна видно
  «Подключена: zayavka_….xlsx».
- **B · Сгенерировать из PIM (CSV)** — после генерации заявка **сама
  подключается** к сессии. В десктопной версии сначала спрашивается каталог
  сохранения (мастер §5).

### 1.2. Генератор заявки — новые правила заполнения (по вашему требованию)
| Колонка | Было | Стало |
|---|---|---|
| D «Организация» | поле в UI | **`photo production`** — всегда, без поля |
| P «Фотограф» | поле в UI (Кирилл) | **пусто** (заполняете вручную; допустимы 2 фотографа) |
| E «Дата съемки» | поле в UI | **пусто** (вручную/не заполняется) |
| Имя файла | `zayavka_<дата из поля>.xlsx` | `zayavka_ДД.ММ.ГГГГ.xlsx` — **сегодняшняя дата автоматически** |

Поля «Фотограф / Организация / Дата съёмки» из интерфейса **убраны**.

### 1.3. «Настройки» — настоящее окно (был только тост-подсказка)
Секции:
- **Sidecar (Python)** — статус/порт, версия, движки ШК (OpenCV/ZXing/PyZBar),
  кэш ШК→артикул, каталог данных, текущая заявка;
- **APIM v3** — окружение (preprod/prod) и вкл/выкл — применяются на лету
  (новый RPC `system.set_apim`, кэш SQLite при этом сохраняется);
- **Журнал Undo** — счётчик записей + «Очистить» (новый RPC
  `renamer.journal_clear`);
- **Горячие клавиши** — справка (⌘Z, R, Space, Esc).

### 1.4. Прочее
- «+» в блоке «Сессии» теперь открывает нативный выбор папки (был тост).
- Повторное использование стабильного sidecar из предыдущего патча
  (panic-free супервизор, auto-restart, `sidecar://ready|dead|error`,
  `Child::id()` под Rust 1.98) — файл `src-tauri/src/sidecar.rs` в патче
  финальный, актуальный.

### 1.5. Новые/изменённые RPC (к разделу 8 мастер-файла)
| Метод | Статус |
|---|---|
| `system.set_apim` `{env, enabled}` | НОВЫЙ |
| `renamer.journal_clear` → `{cleared}` | НОВЫЙ |
| `zayavka.generate` (без полей; `out_path` может быть каталогом; ответ `+date`) | ИЗМЕНЁН |
| `system.info` `+apim:{env,enabled}` | ИЗМЕНЁН |
| `session.set_zayavka` (enrich) | подтверждён, без изменений |

## 2. Как применить (на маке)

Все файлы из архива копируются **по тем же путям** в ваш проект
(`/Users/macbook/Downloads/raw-renamer-studio/`) — пути в архиве уже совпадают
(корневая папка архива = корень проекта).

```bash
cd /Users/macbook/Downloads
# 1) распаковать патч (пути совпадут сами; если распаковываете в вложенную
#    папку — перенесите содержимое по структуре, см. список ниже)
unzip patch-full-2026-09-18.zip -d patch_tmp
cp -R patch_tmp/raw-renamer-studio/* raw-renamer-studio/
rm -rf patch_tmp

# 2) зависимости не менялись (plugin-dialog уже в package.json) —
#    npm install не обязателен, но если что:
cd raw-renamer-studio
npm install --no-audit --no-fund

# 3) сборка (Rust-ядро не менялось в этом патче — соберётся быстро)
bash scripts/build-macos.sh
```

## 3. Чек-лист проверки на маке (пройдите по порядку)

1. **Запуск** — `.app` стартует, 2–5 с «SIDECAR OFFLINE» → зелёный статус.
   При ошибке — тост «Ошибка sidecar» с причиной (и `[sidecar] …` в Console.app).
2. **Открыть папку** (наст. пример RAW) — товары распознаются.
3. **Заявка → A · Открыть .xlsx** — ваш реальный файл заявки:
   - в шапке окна «Подключена: …xlsx»;
   - у товаров появились Код LM / названия / строки.
4. **Заявка → B · Сгенерировать** (PIM-csv):
   - спрашивается каталог сохранения;
   - в каталоге `zayavka_ДД.ММ.ГГГГ.xlsx`;
   - открыть xlsx: D-колонка = `photo production`, E (Дата съемки) и
     P (Фотограф) — **пустые**; заявка уже подключена к сессии.
5. **Настройки** — окно открывается; переключить APIM (preprod/prod, вкл/выкл)
   → тост «сохранены»; «Очистить» журнала (если есть записи).
6. **Переименование** (главное): «Переименовать всё» → план (главный без
   суффикса, `_y`, `_01…`) → подтвердить → файлы переименованы, в xlsx
   L/M записаны. Тост «Отменить ⌘Z» → откат: имена и L/M вернулись.
7. **Excel заблокирован**: открыть заявкx в Excel → переименовать →
   ошибка «Закройте файл… «Повторить»» → закрыть Excel → «Повторить» → L/M
   записались.

Если что-то из пунктов 3–7 поведёт себя не так — присылайте:
- для UI: скрин + что кликаете;
- для сбоев: Console.app → лог процесса «RAW Renamer Studio» (строки
  `[sidecar] …`).
