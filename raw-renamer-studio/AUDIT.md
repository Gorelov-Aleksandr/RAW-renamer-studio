# RAW Renamer Studio — Глубокий аудит (QA + UX + архитектура)

**Дата:** 2026-09-18 (МСК) · **Платформа:** macOS (Tauri v2 + React + Python-sidecar)
**Стек:** Tauri 2 (Rust) · React 18 + TypeScript + Tailwind · FastAPI sidecar (PyInstaller onefile в release)
**Метод:** статический аудит + **runtime-проверка** (поднят sidecar, прогнаны реальные RPC/HTTP) +
автоматизированный тест-сьют (80 тестов) + перф-замеры. Отчёты разработчиков не принимались на веру —
всё воспроизведено запросами.

> **Кратко:** найдено и **исправлено в v3.3** 22 бага/дефекта (3 HIGH в рантайме, 2 HIGH в Tauri,
> 1 HIGH — отсутствие capability, 2 HIGH в sidecar), добавлено 80 автотестов и перф-профиль.
> Тесты: **80 passed**. Rust/Tauri-часть написана по API, но **не компилировалась в песочнице**
> (нет cargo) — требует сборки на macOS (раздел «Ограничения»).

## 2. Детальные баг-репорты (ключевые)

Формат: ID / Компонент / Шаги / Ожидаемо / Фактически / Серьёзность / Рекомендация / Статус.

### G1 — Drag&drop кадров в UI сломан (контракт move_frame)
- **Компонент:** `src-python/server.py` (`session.move_frame`) ↔ `src/store/useSession.ts` (`moveFrame`)
- **Шаги:** открыть партию → в карточке товара перетащить кадр A на позицию B (DnD в RightPanel).
- **Ожидаемо:** кадры меняются местами, план переименования учитывает порядок.
- **Фактически:** sidecar возвращал `4000 «Индекс вне диапазона»` — сервер читал `p['to_idx']`, а фронт присылал `idx` → `KeyError`/`None` → валидация падала. DnD кадров **не работал** в приложении.
- **Серьёзность:** HIGH (сломан базовый UX-скрин).
- **Рекомендация:** единый ключ. Исправлено так: сервер принимает `to_idx` **или** `idx` (обратно совместимо).
- **Статус:** ✅ фикс + регрессионный тест `test_move_frame_bounds`.

### G2 — Гонка старта: первый RPC получает ConnectionRefused
- **Компонент:** `server.py` (`main`) — порядок «порт-файл/READY → accept».
- **Шаги:** запустить sidecar; первый же RPC/heartbeat сразу после `SIDECAR_READY`.
- **Ожидаемо:** сервер уже принимает (READY означает готовность).
- **Фактически:** `SIDECAR_READY` и `.sidecar/port` писались **до** того, как uvicorn начал `accept`.
  В окно ~100 мс первый запрос → `ConnectionRefused`. Интермитентно: один запуск — сбой heartbeat,
  следующий — ок. (Повторено в тестах: фикстура стала требовать реальный 200 с `/health` после READY.)
- **Серьёзность:** HIGH (случайный «офлайн» при старте, ложные тосты).
- **Рекомендация:** объявлять готовность **после** `server.started`.
- **Статус:** ✅ фикс (фоновый `_announce` ждёт `server.started`, затем пишет порт-файл и READY).

### B1 — open_folder мог превысить FE-таймаут (APIM последовательно)
- **Компонент:** `lookup.py` / `server._enrich`.
- **Шаги:** папка со 100+ товарами, которых нет ни в заявке, ни в кэше → каждый идёт в APIM.
- **Ожидаемо:** `open_folder` укладывается в FE-таймаут 120 с.
- **Фактически:** APIM вызывался **по одному**, на каждый до 5 с таймаута. 100 новых × 5 с = 500 с ≫ 120 с
  → фронт обрывал, сессия «не открылась».
- **Серьёзность:** HIGH (большая партия без кэша не открывалась).
- **Рекомендация:** параллельный lookup + circuit breaker.
- **Статус:** ✅ фикс (ThreadPoolExecutor 6 воркеров; 3 сетевых сбоя → APIM на 60 с не трогаем;
  быстрый каскад заявка→кэш остаётся последовательным и дешёвым).

### B2 — file.download читал произвольный файл
- **Компонент:** `server.py` (`file.download`).
- **Шаги:** RPC `file.download {path: "/etc/hostname"}` (любой путь ≤25 МБ).
- **Ожидаемо:** выдача только файлов sidecar.
- **Фактически:** возвращал base64 любого файла, который мог прочитать процесс.
- **Серьёзность:** HIGH (произвольное чтение через WebView).
- **Статус:** ✅ фикс (только поддерево `data_dir`, иначе 4003) + тест `test_file_download_data_dir_allowed`.

### T3 — Нативный диалог папки заблокирован в собранном app (нет capability)
- **Компонент:** `src-tauri/` — отсутствие `capabilities/`.
- **Шаги:** собрать release → нажать «Открыть папку…» / ⌘O.
- **Ожидаемо:** открывается NSOpenPanel.
- **Фактически:** в Tauri v2 IPC-команды плагинов разрешаются capability; при **отсутствующем**
  `capabilities/default.json` `dialog:open` не разрешён → `open()` отклоняется политикой.
- **Серьёзность:** HIGH (ключевой сценарий «открыть папку» не работает в продукте).
- **Рекомендация:** минимальный capability-файл.
- **Статус:** ✅ `capabilities/default.json` (`core:default`, `dialog:default`), окно `main`.

### D1 — Зомби-sidecar после выхода из приложения
- **Компонент:** `src-tauri/src/sidecar.rs`.
- **Шаги:** запустить app → закрыть (⌘Q).
- **Ожидаемо:** Python-процесс завершён.
- **Фактически:** Python — дочерний процесс; на Unix при смерти родителя **не убивается** → остаётся
  слушающим порт. Следующий запуск — конфликт/лишний процесс.
- **Серьёзность:** HIGH (ресурс, порты, непредсказуемость).
- **Статус:** ✅ `SidecarState.child` (общий `Mutex<Option<Child>>`) + `kill_sidecar()` вызывается из
  `RunEvent::Exit`/`ExitRequested`; supervisor при `kill_requested` не перезапускает.

### D2 — Ложная смерть движка (App Nap) и «сгорание» рестартов
- **Компонент:** `sidecar.rs` (watchdog 8 с) + `MAX_RESTARTS=3` без сброса.
- **Шаги:** перевести Mac в сон / App Nap (WebView-таймеры уходят в фон) → heartbeat (каждые 3 с)
  не приходит > 8 с → Python `exit(0)` → supervisor рестартит. Повтор 3 раза → «авто-рестарт остановлен».
- **Серьёзность:** HIGH (app после сна может остаться без движка навсегда).
- **Статус:** ✅ watchdog 30 с (запас под Nap) + сброс `restarts=0` после `STABLE_RESET=300 с`
  стабильной работы.

## 3. Производительность (замеры, Linux-песочница)

`pytest tests/test_perf.py` (мягкие пороги, не падают — только профиль):

| Метрика | Значение | Комментарий |
|---|---|---|
| `scan_300_cv` | **4.9 с** | CV-режим, 300 «RAW» (декод превью + попытка ZXing). Порог 60 с. |
| `scan_1000_cv` | **15.7 с** | CV-режим, 1000 файлов. Укладывается в FE-таймаут 120 с с запасом. |
| `scan_1000_names` | **0.03 с** | names-режим (не читает содержимое) — на 3 порядка быстрее CV. |
| `plan_125_items` | **0.001 с** | Построение плана — мгновенно. |

**Выводы / рекомендации (не блокирующие):**
- CV-режим — bottleneck в декоде встроенных JPEG + ZXing. 1000 файлов за ~16 с приемлемо, но для
  партий 3000+ стоит добавить **прогресс скана** (sidecar шлёт `session.scan_progress`) и/или
  параллельный decode (как сделано для APIM). Сейчас прогресса скана нет — UX-улучшение (раздел 4).
- mmap (B13) снизил пик памяти: в RAM только JPEG (1–8 МБ), а не весь 25 МБ RAW.
- `names`-режим на порядки быстрее — при больших партиях без CV-метки рекомендуется.

## 4. UX-улучшения (список)

**Сделано в v3.3:**
1. Жаргон убран из базового UI: «SIDECAR OFFLINE» → «движок не отвечает»; «Каскад… APIM v3 (master §8.3)» →
   «Поиск: заявка → локальный кэш → сервер Леруа Мерлен»; `sidecar :48963` → кликабельный чип «онлайн»
   (ведёт в «О приложении»); «SQLite: N записей» и список движков — только во вкладке «Про».
2. Настройки разбиты: **«Базовые»** (автопоиск, история ⌘Z, горячие клавиши, совет про DnD) и
   **«Для профессионалов»** (APIM-окружение, кэш, пути, движки, логи).
3. **⌘O** — открыть папку; **drag&drop** папки/заявки прямо на окно (macOS — нативное событие с путями).
4. **Нативное меню** macOS: О программе · Настройки (⌘,) · Открыть папку (⌘O) · Отменить (⌘Z) · Справка · Выход (⌘Q).
5. Error boundary — сбой рендера не роняет app, есть «Перезапустить».
6. Данные копируемы (артикул/ШК) — убран глобальный `user-select:none` для текста.
7. Битое превью больше не ломает карточку (`onError` → иконка).
8. Мёртвая кнопка «Разделить товар» убрана.
9. Ошибки — человеческими: права macOS («Системные настройки → Приватность → Файлы и папки»),
   коллизия LM (какой код у каких товаров), отсутствующие файлы при undo — явно перечисляются.

**Рекомендации (не сделаны, по приоритету):**
- **Прогресс скана** для больших партий (CV): индикатор «Сканирую 340/1000…» (sidecar-событие + прогресс-бар).
- **C6:** индикатор «свежий Excel» — сбрасывать по таймеру/тиканию (сейчас только при смене состояния).
- **C7:** повторный poll `sidecar_url` при возврате из офлайна (сейчас опрос только до готовности).
- **a11y:** `role`/`aria-selected` на карточках и пунктах палитры; фокус-ловушка в модалках.
- **Контраст:** чипы статуса на превью (белый текст на `black/50`) — проверить на WCAG AA при ярких фото.
- **Внешний диск:** при отключении диска в работе — явно предлагать «закрыть партию» (сейчас ошибки чтения папки).
