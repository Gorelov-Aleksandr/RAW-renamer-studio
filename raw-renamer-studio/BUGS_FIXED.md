## Детали по ключевым исправлениям

### BUG-004: детект кодировки CSV (src-python/pim_builder.py)

Старый алгоритм: BOM → иначе `raw.decode('utf-16-le')` (если не упало — «UTF-16»).
Декодирование UTF-16 LE **не падает ни при каких** чётных последовательностях байтов,
поэтому UTF-8 без BOM при чётной длине становился «UTF-16 LE» и превращался в
иероглифы → парсер не находил заголовки.

Новый алгоритм:
1. BOM: `FF FE` → UTF-16 LE · `FE FF` → UTF-16 BE · `EF BB BF` → UTF-8;
2. без BOM: много NUL-байтов (≥12,5% в первых 8 КБ) → UTF-16; порядок байтов —
   по первому встреченному байту-нолю (`x 00` → LE, `00 x` → BE), иначе —
   по доле «смысловых» символов при декодировании LE и BE;
3. иначе строгий UTF-8; fallback — cp1251 (Windows PIM).

Проверено (unit + E2E): UTF-16 LE BOM · UTF-16 LE без BOM · UTF-16 BE BOM ·
UTF-16 BE без BOM · UTF-8 BOM · UTF-8 без BOM (Tab и «;») · cp1251 ·
мусор/пусто/чужие заголовки → информативная ошибка с кодировкой, разделителем
и реальными столбцами файла.

### BUG-001/005: выбор папки в браузере (src/lib/pickFolder.ts, /upload)

- `showDirectoryPicker()` (Chromium/Edge, https) — рекурсивный обход (до 4
  уровней, ≤8192 файлов), фильтруются только RAW-расширения
  (.cr2 .cr3 .arw .nef .orf .rw2 .dng .raf .nrw .pef .x3f — зеркало
  `RAW_EXTS` sidecar);
- fallback `<input webkitdirectory>` (Firefox/Safari);
- `POST /upload` получил необязательное поле `dir` (имя папки, санитизация:
  без `/`, `..`, >80 символов) — файлы попадают в `uploads/<папка>/`;
- дальше открывается обычная сессия (`session.open_folder`) — CV-сканер,
  заявка, переименование, откат работают как в десктопе (проверено E2E:
  22 файла → 6 товаров, все ШК распознаны, план 22 строки, execute+undo OK).

### BUG-006: офлайн-режим (Sidebar, Toolbar, ZayavkaModal, store)

Единый индикатор `online` (heartbeat каждые 3 с, как и раньше). В офлайне:
кнопки некликабельны + tooltip; в окне заявки — жёлтый баннер. Горячая
клавиша ⌘Z в офлайне не шумит ошибкой, а говорит, что sidecar не запущен.

## Как проверить

1. `npm install` и `python3 -m pip install -r src-python/requirements.txt`.
2. `python3 src-python/server.py --port 0 --port-file .sidecar/port --data-dir .data --demo-folder "$(pwd)/demo_batch" --watchdog 0`
3. `npm run dev` → открыть http://localhost:5173.
4. Чек-лист:
   - «+» / «Открыть папку…» → выбор папки (в браузере — с загрузкой RAW);
   - Заявка: «Выбрать файл заявки…» → диалог; drag&drop CSV → парсинг
     (любая кодировка из списка выше);
   - ⋮ → меню с тремя рабочими пунктами;
   - ⌘K / Ctrl+K → палитра: «заявка», «откат», «настройки»…;
   - остановить sidecar → в шапке «SIDECAR OFFLINE», все RPC-кнопки
     заблокированы, тостов-ошибок нет.
